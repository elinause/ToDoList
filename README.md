ToDoList

A simple To-Do List desktop application built with Python and PyQt5.

Features

Add tasks

Delete tasks

Complete tasks using checkboxes

Edit tasks

Clear all tasks

Save tasks to a JSON file

Load saved tasks when the application starts

Technologies Used

Python
PyQt5
JSON

How to Run

Install Python.
Install PyQt5:

pip install PyQt5

Run the application:

python main.py

Project Files

main.py — Main application code

tasks.json — Stores saved tasks

.gitignore — Specifies files Git should ignore
